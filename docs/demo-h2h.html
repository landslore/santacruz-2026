⭐ Opción A (Recomendada)

Badges de Podio para Posición + Solidez Defensiva Invertida

• Posición: Se quita la barra (la posición no es una barra de progreso) y se muestra como insignia de podio destacando al líder.
• Goles en Contra: La barra representa Solidez Defensiva (el que menos goles encaja tiene la barra completa).
• 5 Columnas fijas: Todas las barras miden exactamente los mismos píxeles y el texto central está 100% alineado verticalmente.

Opción B

Hero Card de Clasificación + Barras puras de juego

• Cabecera estilo videojuego/Sofascore: Muestra Posición, Puntos totales y Racha de forma de un vistazo arriba.
• Abajo solo juego: Las barras comparan únicamente goles, solidez y rendimiento casa/fuera.

Opción C

Barra Invertida de Liga (Escala 1 a 14)

• Barra en todo: El 1º clasificado tiene 100% de barra (14/14), el 2º tiene 93% (13/14) y el 14º tiene 7% (1/14).
• Menos es más: Convierte matemáticamente cualquier métrica inversa para que más barra siempre signifique mejor.
